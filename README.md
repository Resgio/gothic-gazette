# The Gothic Gazette 📰🖤

> Nevermore Academy's Forbidden Chronicles — Veritas Morsque Praestat

A dark, atmospheric digital newspaper web application themed around **Wednesday Addams** and **Nevermore Academy**.

## 🦇 Features & Design Specifications

- **Theme & Aesthetic**: Dark Academia / Gothic UI.
  - Charcoal (`#08080A`), Blood Crimson (`#8B0000` / `#D90429`), Bone White (`#E2E2E2`), Muted Gold (`#C5A059`).
  - Google Fonts: *Pirata One*, *Cinzel*, *Playfair Display*, *Inter*.
  - Built with Tailwind CSS and Lucide Icons.
- **Asymmetric Hero Section (The Hex Constraint)**:
  - 65/35 asymmetric grid layout.
  - Headline: *"THE MONSTER OF JERICHO STRIKES AGAIN"*.
  - Off-center featured image with vignette and crimson glow borders.
  - Sarcastic commentary by Wednesday Addams.
- **Editorial News Grid (The Curse)**:
  - Categorized dossiers: *"Academy Secrets"*, *"Occult Lore"*, *"Faculty Whispers"*.
  - Live category filter buttons and interactive archive readers.
- **Author Profiles**:
  - Spotlight cards for Wednesday Addams, Enid Sinclair, and Eugene Ottinger.
- **Whistleblower Secret Portal**:
  - Interactive confidential tip submission modal with custom codenames and animated seal states.
- **In-Universe Guild Integration**:
  - The Kapidhwaj Archives card honoring [@kapidhwaj.innovations](https://instagram.com/kapidhwaj.innovations).

## 🚀 Quick Start

Open `index.html` directly in any modern browser:
```bash
open index.html
```
Or serve locally:
```bash
python3 -m http.server 8080
```
